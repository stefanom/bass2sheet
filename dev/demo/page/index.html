bass2sheet

From a song to a bass part you can read and play.

What the film shows

One song, end to end. A command takes the recording and writes a sheet, staff and tab, and says how far to trust it. The copilot's page then shows the notes on a picture of the isolated bass: you play the song, stop where a note is wrong and fix it, and the same fix is offered for the bars that repeat. The sheet is written from your notes. A page for a phone plays the record without its bass while the score moves along. The transcription is done by machine and makes mistakes; the person stays in charge.

Try it

git clone https://github.com/stefanom/bass2sheet.git && cd bass2sheet
./bootstrap
uv run bass2sheet-copilot serve --dir scores
